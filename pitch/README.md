# MetroQuest pitch

Six-slide pitch using the supplied DevDay reference palette: black, white,
#00B857 green, #9147FF violet, #FFC6B0 peach and #006AFF blue. The inspiration is
visual only; no OpenAI affiliation or AI functionality is claimed.

Editable native deck: https://docs.google.com/presentation/d/15YO5gWM3iXUtirN6qM5rAHUq5Pb8xcTAweBxdiNvIUM/edit

The deck distinguishes implemented local prototype behavior from proposed pilots
and revenue ideas. Journeys are manually logged, social profiles/ranks are sample
data, Android Expo Go was previously verified, iOS runtime remains untested, and
there is no APK delivery.

Final editable PowerPoint: output/MetroQuest-Pitch-2026.pptx.
Final PDF: output/MetroQuest-Pitch-2026.pdf. All six final renders are in renders/.
The authoritative final native layout is source/final-native-deck.json;
source/deck-authoring.json records the initial authoring batch. Source copy is
in source/content.md and screenshot evidence is in assets/.

Slides 3 and 4 embed the actual updated Passport and Home after a manually
logged PCMC → Civil Court ride: 1 journey, 2 endpoint stamps, 13.4 estimated km,
28 estimated minutes and 50 XP. The screenshots were supplied by the engineering
lead after the app UI changed. They are not generated visuals. No old orange UI
or zero-ride suggested route is used as final product evidence.

Authoring used the supported Google Slides connector because the supplied
Artifact Tool dependency loader/runtime was unavailable. Text, geometry and
product-loop diagram remain native editable objects. Screenshot evidence is a
separate embedded image. The final deck is inspected from a PDF render of all
six slides; PPTX package/layout checks are recorded in validation/. Final checks
report six slides, Arial-only text, zero package findings, zero layout findings
and zero layout warnings. PowerPoint desktop was not opened; the PDF render and
native Google Slides readback were inspected.
