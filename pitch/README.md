# MetroQuest pitch

Six-slide pitch using the supplied DevDay reference palette: black, white,
#00B857 green, #9147FF violet, #FFC6B0 peach and #006AFF blue. The inspiration is
visual only; no OpenAI affiliation or AI functionality is claimed.

Editable native deck: https://docs.google.com/presentation/d/15YO5gWM3iXUtirN6qM5rAHUq5Pb8xcTAweBxdiNvIUM/edit

The deck distinguishes implemented local prototype behavior from proposed pilots
and revenue ideas. Journeys are manually logged, social profiles/ranks are sample
data, Android Expo Go was previously verified, iOS runtime remains untested, and
there is no APK delivery.

Source requests are in source/deck-authoring.json. Final PPTX/PDF go in output/;
slide renders are in renders/. Product screenshots must come from the updated
actual application. No old orange UI is used as evidence of the new theme.

Authoring used the supported Google Slides connector because the supplied
Artifact Tool dependency loader/runtime was unavailable. Text, geometry and
product-loop diagram remain native editable objects. Screenshot evidence is a
separate embedded image. The final deck is inspected from a PDF render of all
six slides; PPTX package/layout checks are recorded in validation/.
