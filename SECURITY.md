# Security

MetroQuest is a local-first demo. There is no production auth, payments, or operator integration.

## Reporting

If you find a vulnerability in this repository or the GitHub Pages demo, open a private report with the maintainers (repo owner) or email the team lead via the DevDay WhatsApp group. Do not file a public issue for exploitable bugs.

## Scope

In scope: XSS or storage issues in the Expo web demo that could affect someone using the public Pages site.

Out of scope: claims about Pune Metro systems, ticketing, or GPS — those are not implemented.
